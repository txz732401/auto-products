# MarkdownForge

> 一个关于 markdown 的轻量工具

针对 markdown 的在线工具站，参考 GitHub 上的优秀开源项目重新设计的纯静态版本。开箱即用，无需安装。

## 目标用户

- 独立开发者
- 日常需要快速处理这类任务的人
- 想学习这类项目实现方式的人

## 核心功能

- 在线 markdown 处理 (浏览器内运行, 不上传数据)
- 实时预览 + 一键复制结果
- 整合精选开源项目的最佳实践

## 价值主张

不用装环境，打开网页就能用；参考成熟开源项目的处理逻辑；无登录也能用。

## 变现方向

未来可考虑：Pro 版批量处理 / 企业部署 / 定制功能收费

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 部署到线上

- GitHub Pages: 推到仓库，开启 Pages
- Vercel/Netlify: 拖拽静态文件夹即可
