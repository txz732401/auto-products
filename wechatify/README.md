# WeChatify

> Markdown 直达微信，排版零烦恼

专为技术开发者设计的在线 Markdown 转微信公众号排版工具。支持实时预览、LaTeX 公式渲染及本地图片自动上传，一键生成适配微信富文本编辑器的格式。

## 目标用户

- 技术博客作者
- 开发者

## 核心功能

- 实时 Markdown 预览与微信样式同步
- LaTeX 数学公式转 SVG 渲染
- 本地图片自动上传至图床
- 一键复制适配微信编辑器的富文本

## 价值主张

无需安装插件或配置本地环境，浏览器即可使用，解决开发者写作后手动调整 CSS 排版的痛点，比传统编辑器更轻量，比插件更通用。

## 变现方向

免费基础功能；高级订阅提供无限图片存储、自定义品牌模板、多平台（掘金/知乎）一键发布。

## 参考的开源库

- [barretlee/online-markdown](https://github.com/barretlee/online-markdown) - ★919 - A online markdown converter specially for Wechat Public formatting.
- [DavidLam-oss/obsidian-wechat-converter](https://github.com/DavidLam-oss/obsidian-wechat-converter) - ★207 - Obsidian 公众号排版 + 多平台发布插件。Markdown 转公众号样式、一键同步草稿箱、支持知乎/掘金/小红书等 20+ 平台草稿投递、LaTeX 数学公式 (SVG)、本地图片自动上传。让技术写作回归纯粹。

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 部署到线上

- GitHub Pages: 推到仓库，开启 Pages
- Vercel/Netlify: 拖拽静态文件夹即可
